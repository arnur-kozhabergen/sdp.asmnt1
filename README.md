# Build Your Apartment

## Product
Apartment has characteristics square meters, floor, address, complex name, comfort class, move-in readiness, concierge service and smart home features.

## How to build representations

### Standard Apartment
Use `StandardApartmentBuilder` — builds a basic apartment without any luxury features.

### Luxury Apartment
Use `LuxuryApartmentBuilder` — builds a premium apartment with concierge service and smart home.

## Director
`ApartmentDirector` has two ready-made configurations:
- `buildStudio()` — compact basic apartment
- `buildPentHouse()` — large luxury apartment on a high floor
